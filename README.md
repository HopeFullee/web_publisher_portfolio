## 웹 퍼블리셔 포트폴리오

**기간**: 2022.01 - 2022.02

**역할/구성**: 웹 퍼블리셔 1명 (본인)

**사용 기술**: JavaScript, HTML, CSS, React.js, Three.js, Adobe Ps

**배포**: https://hopefullee.github.io/web_publisher_portfolio/

### ✅ 주요 작업 내용

#### 독창적인 디자인 컨셉 기획 및 Asset 제작

- '게임'과 '픽셀 아트'를 결합한 유니크한 컨셉 기획으로 기존 포트폴리오와의 차별성 확보
- 어도비 포토샵(Ps)을 활용하여 캐릭터, 배경 등 픽셀 아트 에셋을 직접 수제작
- 라이선스 프리 소스(Pixabay, Unsplash, Sketchfab 등)를 선별하여 프로젝트 아이덴티티에 최적화된  리소스를 수집하고 디자인 툴을 활용해 커스텀 Asset 제작

#### 고급 인터랙션 및 애니메이션 구현

- **Sprite Animation**: 캐릭터 움직임을 구현하기 위해 스프라이트 기법을 적용, 인터랙티브한 사용자 경험 제공
- **Vanilla JS Carousel**: 카로셀 슬라이더를 직접 설계하여 스크립트 동작 원리 및 DOM 제어 역량 확보
- **Three.js 3D Rendering**: GLTF 3D 모델 렌더링을 시도하여 웹 환경에서의 공간감 있는 연출 구현

#### React 기반의 SPA 아키텍처 구축
- 퍼블리싱 수준을 넘어 React.js를 독학으로 도입하여 SPA(Single Page Application) 환경 구축
- 컴포넌트 중심의 설계를 통해 유지보수가 용이한 소스코드 구조 설계

### 🎉 주요 성과

- **기술적 한계 돌파를 통한 자기주도적 성장**: 정규 교육과정 외의 기술(React, Three.js)을 독학으로 병행 학습하여 기획안을 100% 구현해내는 문제 해결 역량 증명
- **디바이스 최적화에 대한 시야 확장**: Three.js 활용 중 저사양 기기에서의 성능 저하를 경험하며, GPU 리소스 최적화 및 크로스 브라우징의 중요성 체득
- **커리어 전환의 성공적 발판 마련**: 독창적인 컨셉과 기술적 완성도를 인정받아 수료 후  두 번의 성공적인 이직을 이끌어낸 핵심 포트폴리오로 활용
